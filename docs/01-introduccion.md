# 01. Introducción

## Introducción

Este documento toma como referencia la Especificación de Requisitos de Software (ERS) del Sistema Experto para Diagnóstico de Enfermedades (XpertDiagnostic). Se estructuró con las directrices del estándar IEEE, Práctica Recomendada para Especificaciones de Requisitos Software, ANSI/IEEE 830, 1998. Su objetivo es el diseño del Sistema Experto para Diagnóstico de Enfermedades.

## Propósito

Definir los requisitos funcionales y no funcionales para el desarrollo correcto de un sistema experto para el diagnóstico de enfermedades.

El sistema será usado por médicos profesionales de los siguientes niveles, en instituciones de salud públicas y privadas:

- Médicos internos de pregrado.
- Médicos pasantes realizando su servicio social.
- Médicos adscritos familiares.
- Médicos especialistas.
- Médicos jefes de servicio de especialidad.

## Alcance

XpertDiagnostic brindará a los médicos:

- una predicción probabilística en una fase de pre-diagnóstico, y
- una predicción determinista en la fase de generación de diagnóstico y tratamiento,

de las enfermedades que padecen los pacientes bajo su atención. Utiliza una base de conocimiento y una máquina de inferencia para sugerir posibles diagnósticos según los signos, síntomas, resultados de estudios de laboratorio y otros datos ingresados por el médico tratante.
